# ⚡ ROOT DUEL (ТЕЛЕВИЗИОННАЯ МАТЕМАТИЧЕСКАЯ ДУЭЛЬ)

Полноценная браузерная игра в стиле телевизионной математической дуэли для двоих игроков на одном смартфоне или одного игрока против адаптивного искусственного интеллекта.

## 📱 Особенности Mobile-First дизайна

1. **Игра на одном смартфоне лицом к лицу**:
   - Телефон кладется на стол между двумя участниками.
   - Игрок 1 играет снизу, Игрок 2 — сверху.
   - **Разворот интерфейса на 180°**: кнопка `🔄` в верхнем меню переворачивает панель Игрока 2 (счет, кнопки, клавиатуру) вверх ногами для телефона, но лицом к сопернику!
   - Симметричные зоны нажатия и равный размер кнопок.

2. **Собственная сенсорная клавиатура**:
   - Без неудобных стандартных полей ввода и всплывающей системной клавиатуры.
   - Большие клавиши `[1-9, ±, 0, ⌫, ГОТОВО]` размером 44–60 px.
   - Мгновенный отклик на нажатие (`pointerdown`), вибро/аудио тактильность.

3. **Адаптивность под все экраны**:
   - Поддержка `100dvh` для исключения артефактов мобильных браузерных плашек.
   - Полная поддержка `env(safe-area-inset-top)` / `bottom` (вырезы Dynamic Island, челки iPhone).
   - Защита от случайного скролла, выделения текста и двойного тапа зума (`user-select: none`, `touch-action: manipulation`).

4. **Адаптация под ПК / Wide Screen**:
   - На широкоформатных экранах (ПК, планшеты, ТВ) интерфейс перестраивается в телевизионную сцену: Игрок 1 слева, меловая доска по центру, Игрок 2 справа.
   - Поддержка клавиатуры:
     - **Игрок 1:** `[A]` — нажать кнопку ответа; цифровые клавиши `0-9`, `Enter`.
     - **Игрок 2:** `[L]` — нажать кнопку ответа; цифровой блок Numpad `0-9`, Numpad `Enter`.
     - **1 Игрок против ИИ:** `[Пробел]` — кнопка ответа.

## 🎯 Игровой процесс и правила

1. **Вопрос на табло**: В центре загорается телевизионное табло с математической задачей (квадратные корни, кубические корни, степени, арифметические выражения).
2. **Убывающий счет**: В каждом раунде банк очков начинает уменьшаться с **50** до **10**. Чем быстрее игрок жмет кнопку и отвечает, тем больше очков получает!
3. **Битва за кнопку**: Первый, кто нажал большую кнопку `ОТВЕТИТЬ`, получает право хода. Второй игрок временно блокируется.
4. **Ввод ответа**: У игрока есть таймер-полоса (6 секунд) на ввод ответа.
5. **Проверка и реванш**:
   - **Верно:** банк очков начисляется игроку, звучит триумфальный джингл, зеленый флеш.
   - **Ошибка:** штраф (-5 очков), звучит зуммер ошибки, а соперник получает право на **перехват (Rebound)**!
6. **Финал матча**: Статистика правильных ответов, ошибок, среднего времени реакции и церемония награждения победителя.

## 🧮 Категории и уровни сложности

- **Категории:**
  - $\sqrt{x}$ **Квадратные корни** ($\sqrt{1} \dots \sqrt{900}$)
  - $\sqrt[3]{x}$ **Кубические корни** ($\sqrt[3]{1} \dots \sqrt[3]{1728}$, отрицательные числа)
  - $x^n$ **Степени** ($2^3 \dots 2^{10}$, $3^4$, $5^4$, квадраты)
  - $\pm$ **Выражения** ($\sqrt{81} - 4$, $\sqrt{144}/12$, $\sqrt{196} - \sqrt{49}$)
  - 🎲 **Смешанные**
- **Сложность:**
  - `ЛЕГКО`: базовые корни до 10, простые квадраты.
  - `НОРМА`: корни до 20, кубические корни, составные примеры.
  - `ХАРД`: скобки, дроби, степени выше 4, отрицательные числа.

## 🔊 Синтезатор звука (Web Audio API)

В игре нет тяжелых сторонних MP3/WAV файлов — все звуки (зуммер телевикторины, отсчет 3-2-1, щелчки клавиш, арпеджио правильного ответа, триумфальная победная фанфара) генерируются в реальном времени через браузерный Web Audio API.

## 🚀 Запуск игры

Просто откройте `index.html` в любом браузере или запустите локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```
